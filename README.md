# liberty-aero.com

Parts search + RFQ site for Liberty Aero Services. Deployed by Netlify from this repository.

- `public/` is the published site (index.html, icons, share image, robots, sitemap, redirects).
- `public/parts.json` is the public inventory snapshot (P/N, description, condition, quantity, lead). No supplier, cost or price data.
- `netlify.toml` holds the Netlify build and header settings.
